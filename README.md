# RSI for Long-Horizon Reasoning

Choose a language:

- [English](README.en.md)
- [简体中文](README.zh.md)

This project studies whether long-horizon behavior induced by an external harness can be internalized into a student model. The project is currently in preparation; the toy demo is an interface check, not research evidence.

本项目研究如何将外部 Harness 诱导的长程行为内化到学生模型。目前处于准备阶段；toy demo 只检查接口，不代表研究结果。
