# 研究问题与假设

**当前要验证的不是“完整 RSI 是否能运行”，而是 K 审查轨迹能否在移除 K 后成为学生的独立长程能力。**

更新日期：2026-10-26

## 研究问题

在固定部署 Harness h0 和相同学生起点下，由固定 Harness/审查器 K0 产生的、经过执行前审查的长程交互轨迹，能否通过 SFT 内化为学生行为，使其在移除审查器和私有 K 后，对未见任务获得比普通自训练更好的成功率或长程状态保持能力？

这是一条待验证的问题，不是已确认的创新主张。Harness-Zero 已展示审查轨迹到 SFT 的工程链；本项目还必须确认一个具体长程失败机制，并证明 K 数据相对公平对照具有增量。

## 暂定机制

优先调查长交互中的状态/约束漂移：模型早期看到的前置条件、已完成子目标或资源约束，在后续动作中没有被持续遵守。P0/P1 必须用真实轨迹确认；若失败主要来自工具协议、身份匹配或错误恢复，应改写机制。

能力内化只指：在学生继续拥有同一公开工具、文件系统和 h0 的情况下，权重学会更可靠的状态维护、检查或恢复。移除的是私有 reviewer/K，不是环境本身提供的合法观察与工具。

## 可证伪假设

- **H1 外部指导可执行：** M0+h0+K0 的 accepted action 比裸学生更符合公开状态和动作约束。
- **H2 指导数据可内化：** 在学生起点、部署 h0、任务覆盖和训练预算相同的条件下，B3 reviewer-free 结果优于 B2。
- **H3 增量属于 K 而非教师或数据量：** 加入同教师无 K、数据量对齐的对照后，B3 仍保留优势。

H1 不成立时暂停 SFT。H1 成立而 H2 不成立时，先排查轨迹可学习性、模板/loss mask、长度截断和 checkpoint 重载，不增加 RSI 轮数。

## 首轮条件

| 条件 | 定义 | 用途 |
|---|---|---|
| B0 | M0+h0，无 reviewer | 裸模型基线和失败分布 |
| B1 | M0+h0+K0/reviewer，只评测 | 外部指导是否有效 |
| B2 | 裸学生可验证轨迹 → SFT → h0 | 普通自训练对照 |
| B3 | K0 审查 accepted 轨迹 → SFT → h0 | 核心内化条件 |
| B4 | 同教师通用审查、无 K，数据量对齐 | 归因给 K 的对照 |

首轮先做 B0/B1；真实指导信号和数据审计通过后才做 B2/B3。

## 指标与控制

- 主指标：reviewer-free task success，按预先定义的依赖深度档报告。
- 过程指标：合法动作率、约束违例、恢复率（只有可靠标注时使用）、步骤、模型调用、审查/替换、token 和成本。
- 控制：学生 checkpoint/tokenizer、h0、任务分组、prompt/chat template、采样参数、训练 token/更新预算、最大步骤、重试规则和 verifier 版本。
- 分析单位：独立 task family/scenario；同族任务不能被当成独立 RSI 重复。

## 主张边界

Q1 通过不等于 Q2 通过；Q2 通过不等于 K 的多轮更新有效；Q3 通过不等于 A 本身变强。任何只在训练任务、带 reviewer 或被挑选的成功样本上提升的结果，都不支持 reviewer-free 泛化。
