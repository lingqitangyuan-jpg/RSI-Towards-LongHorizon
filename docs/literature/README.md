# Agent 长程推理与 RSI 文献库

**长程 Agent 的能力可以通过交互、记忆、搜索、训练和自修改逐层增强，但这些增强只有在撤去外部支持后仍能迁移，才接近能力内化。**

这是一份面向中文读者的研究文献库，起始清单来自 `Seminar_01/Note.md`。文献按“它解决哪一步失败”聚类，而不是按论文发布时间排列。每篇卡片都按同一顺序写：

**核心主张。**

🧩问题背景 → ⚙️核心方法 → 📊实验结果 → 🔗谱系位置 → ⚠️局限

这里的“实验结果”只记录论文实际报告的指标。没有核对到数字时，直接写“论文未报告 X”，不把定性宣传改写成定量结论。数字来自作者报告，尚未被本项目复现。

## 横向比较

| 研究簇 | 主要移动的对象 | 论文通常证明什么 | 仍未自动证明什么 |
|---|---|---|---|
| 基础交互/记忆 | 上下文、工具调用、外部记忆 | 当前运行能行动或记住 | 能力进入权重、跨环境保持 |
| 规划/搜索/技能 | 候选轨迹、技能库、计划和压缩状态 | 推理时搜索或资产复用有效 | 撤去搜索/技能库后仍有效 |
| 训练/信用分配 | rationale、过程标签、策略梯度 | 训练信号改善参数模型 | 过程监督器移除后的迁移 |
| RSI/自修改 | Agent 代码、元机制、候选档案、Harness | 可继承变体或部分改进器迁移 | 严格控制下改进器本身更会改进 |
| Benchmark | 任务、环境和验证器 | 提供可重放的成绩 | 解释失败原因和因果贡献 |

## 当前项目的操作性术语

- **广义自我改进**：系统利用自己的输出或经验改善后续表现。
- **结构性 RSI**：改进结果能回到后续系统或可继承工件中，形成持续回路。
- **狭义 RSI**：有对照证据表明，演化后的改进器比初始改进器更能产生高质量后继版本。

三者是递进条件。分数随轮次上涨、代码可编辑或存在元代理，都不足以单独证明狭义 RSI。

## 与本项目的连接

当前 IDEA 由 Harness-Zero 的能力内化路径和 HyperAgents 的可编辑元机制启发。它要回答的不是“是否能找到一个高分 Harness”，而是三个分开的问题：

1. 私有 Harness 是否能让当前学生完成更多长程任务？
2. 由它审查和执行的轨迹，是否让学生在固定 h0、撤去审查者后仍能独立完成未见任务？
3. 演化后的元机制是否比初始元机制更有效地产生这种可内化的 Harness？

在这三个问题尚未分别有证据前，本库不把当前 IDEA 写成已成立的贡献。
