## 推荐准备顺序

1. 核实 D/E 盘类型和 WSL 虚拟磁盘实际位置，询问可用远程 Linux/Docker 服务；确定数据/镜像存放位置。当前余量看起来可提供空间选项，但尚未确认 Docker 能否使用这些卷。
2. 决定是否保留 Ubuntu 20.04 并用 `uv` 建 Python 3.12/3.13 环境，或改用受支持的新发行版/远程 Linux。保留当前 Python 3.8 系统环境，不直接覆盖系统 Python。
3. 在确认有足够宿主磁盘空间后安装/启用 Docker；先跑 HZ 无模型单测，再评估 AppWorld `build.py --prepare-only` 与镜像验证，数据下载和镜像构建分开执行。
4. 建一个最小 GPU 兼容性检查，记录 PyTorch/CUDA 版本、可用显存和正在占用 GPU 的进程；不因 `nvidia-smi` 可见就认定模型训练可行。
5. 联系/确认模型与 API 访问、训练服务和预算，先确定可复现的学生/teacher 组合；令牌放本地环境变量，不进 Git。
6. 一旦任务环境可用，按[benchmark pilot 协议](benchmark_pilot_protocol.md)完成单任务 reset→action→observation→verifier，再决定 B0/B1 小样本配置。
