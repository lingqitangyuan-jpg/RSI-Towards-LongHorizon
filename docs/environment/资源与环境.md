## 使用约束

- 大文件、环境、缓存和运行结果放在已分配的 sdf/lyf 目录，不放 /home，不使用 sdk。
- 每次运行前重新执行 nvidia-smi，确认目标 GPU 空闲；不停止未知进程。
- 不修改公共 Conda base、系统 CUDA/驱动、DNS、其他用户目录或 .bashrc。
- 网络不可用时，在本地下载固定版本后传输，并保留校验值。
- 9901 在用户重新明确允许前不连接、不上传、不运行。

## 当前仍需确认的实验条件

这些是项目条件，不再用“向管理员申请目录/调度器”作为泛化阻塞项：

- 学生模型、教师模型或 API 的合法访问与预算；
- 为当前无 Docker adapter 接入真实学生 policy、补齐可审计 launcher；
- 按许可准备 3–5 个不同 API 任务，核验依赖、重置与执行 profile 兼容性；
- 训练后端能否完成 LoRA/SFT 保存、重载和无 reviewer 推理；
- 服务器共享目录的个人配额和长期清理规则。

Docker 权限、Compose 和三个镜像仅在重新选择容器路线时才需要处理。管理员无需为本轮已验收的私有工具再配置 Docker。执行端限制不等于整个 controller/world/verifier 的资源配额；并行运行前另做预算。

环境验收原始快照见 `records/2026-10-26_基础环境验收.md` 和同目录的 `server_snapshots/2026-10-26/`。

只检查 AppWorld 官方环境时，另开一个 SSH 终端，使用：

```bash
source /nfs-data/sdf/lyf/rsi-long-horizon/scripts/activate_appworld_native.sh
python --version
which python
```

这个入口激活独立虚拟环境，并屏蔽 GPU。需要做 PyTorch/CUDA 实验时，另开终端使用原来的 `activate.sh`。

当前 Agent 代码隔离使用第三个入口：

```bash
source /nfs-data/sdf/lyf/rsi-long-horizon/scripts/activate_appworld_rootless.sh
cd /nfs-data/sdf/lyf/rsi-long-horizon/code/RSI-Towards-LongHorizon
export RSI_ROOTLESS_RUN_ID=rootless-p0-$(date -u +%Y%m%d-%H%M%S)
bash scripts/server/run_appworld_rootless.sh
```

这是无模型的工程验收。**source 只选择环境，不自动隔离任意后续命令**；只有经 adapter 运行的生成代码进入沙箱。

当前方案、边界和命令见 [无 Docker 执行方案](无Docker执行方案.md)，最新证据见 [无 Docker 验收](records/2026-10-26_AppWorld无Docker验收.md)。[原生验收](records/2026-10-26_AppWorld原生验收.md) 与 [部署预检](records/2026-10-26_AppWorld部署预检.md) 保留其历史事实。
