## 5. 离线安装与复现

9901 的安装源域名解析失败；9902 和 22 节点访问外部 HTTPS 安装源超时。因此本轮采用：公共 Miniforge 已缓存的 28 个 Conda 包 → 创建私有 Python 环境；Windows 下载官方 Linux 安装包 → 传到数据站 → 在 22 节点离线安装。

PyTorch 固定为 2.6.0+cu124、NumPy 固定为 2.2.6，只用于建立可验证的最小组合，不保证后续训练后端与该版本组合兼容。正式训练环境应按选定工具单独锁定版本。

安装输入位于项目 configs/server/gpu_smoke_requirements.txt 和 gpu_smoke_linux_cuda_requirements.txt。后一个文件显式列出 Linux CUDA 依赖，避免 Windows 下载工具遗漏按 Linux 条件声明的包。

服务器 reports/ 已保存 Conda 来源记录、pip 版本锁、Conda 显式清单及 GPU 验收 JSON；对应小文件已同步到 [本地日期快照目录](../server_snapshots/2026-10-26)。wheelhouse/SHA256SUMS 用于校验所有传输的软件包。Conda 显式清单记录的是本服务器公共缓存中的文件来源，不能单靠这份清单在任意机器上联网重建；应同时保留来源记录、pip 锁和离线安装包。

离线包保留在服务器 wheelhouse/ 和本地 E:/rsi-server-setup/wheelhouse-cu124-py312，便于网络受限时重建；它们是软件安装包，不是模型权重。

源码中的脚本位于 scripts/server/：create_conda_from_cache.py、activate.sh、install_gpu_smoke.sh、accept_gpu_environment.py。详细的新手操作说明见 [服务器使用入门](../服务器使用入门.md)。
