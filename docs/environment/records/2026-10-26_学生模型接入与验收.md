## 安装在哪里，为什么要分开

所有服务器路径都在 /nfs-data/sdf/lyf/rsi-long-horizon 下：AppWorld 使用 envs/appworld-native-py312；模型使用 envs/student-qwen35-py312，继承私人基础环境的 PyTorch。两者通过 JSON 管道交换消息，避免升级模型依赖时破坏已验收的 AppWorld。

模型只做推理；生成的 Python 经现有 Bubblewrap 执行端运行，再由可信控制器调用公开 API。执行端退出后才运行独立官方评分。激活某个 Python 环境不会自动隔离任意代码。

权重下载在本地 E 盘进行，再传到服务器 models/Qwen3.5-9B-c2022362；缓存、环境与权重均不放服务器 /home。ModelScope 只作为传输镜像，验收身份仍以固定 Hugging Face revision 的官方文件哈希为准。

当前未安装 flash-linear-attention / causal-conv1d 加速组件，模型库提示使用 PyTorch 后备实现。先验收功能与实际耗时；不将其速度当作优化后吞吐量，也不为消除提示而立即改动已固定依赖。

## 两类 profile 的解释

工程 smoke：关闭 thinking、greedy、每次最多生成 1024 tokens、最多 8 个环境动作。它用来定位模型协议、执行与评分是否连通。正式 B0/B1 候选：开启 thinking、固定采样参数与 seed、8192 tokens、64 动作；正式预算须在比较前冻结。工程轨迹不能与正式基线合并统计。

单个 train fixture 只足以做工程验收。即使任务完成，也不能据此推断跨任务泛化、长程能力内化或论文主结论。
