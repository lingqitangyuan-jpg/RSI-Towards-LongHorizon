## 4. 怎样指定 GPU

先查看：

```bash
nvidia-smi
```

每行对应一张物理 GPU，编号从 0 开始。看显存占用、利用率和进程列表，避开其他人的工作。“直接指定使用”不代表某张卡永久归你，上次空闲的卡，下次可能已经被使用。

假设你确认 **物理 0 号卡**空闲，可以这样运行自己的程序：

```bash
CUDA_VISIBLE_DEVICES=0 python your_script.py
```

把 `your_script.py` 换成实际文件名。这条命令让程序只看到物理 0 号卡。

程序内部看到的第一张卡叫 `cuda:0`。即使改成 `CUDA_VISIBLE_DEVICES=3`，程序内部仍写 `cuda:0`，此时对应物理 3 号卡。这是两个不同的编号视角。

本次验收脚本按 GPU 的唯一编号（UUID）选择卡，并在开始前检查其空闲状态。程序退出后释放 GPU，不会持续占卡。

## 5. 哪些事情自己做，哪些找管理员

| 你可以自己完成 | 需要管理员处理的典型情况 |
|---|---|
| 在已分配的 `sd*/lyf` 建文件夹 | 扩大配额、开放新目录、更改他人目录权限 |
| 创建自己的 Conda 环境、安装 Python 包 | NVIDIA 驱动损坏、需要调整系统驱动 |
| 按已确认规则选择空闲 GPU | 多人争用、需要长期预约或改变使用规则 |
| 运行、查看、停止自己的程序 | 整台机器异常、GPU 硬件报错 |
| 清理自己的日志和无用环境 | 共享盘满了，需要清理别人的文件 |
| 本地下载软件包再传到自己的目录 | 调整服务器 DNS、代理或外网访问策略 |

你不需要让管理员替你安装每一个 Python 包。本轮借用已有公共 Conda 程序，在你的 sdf 目录创建独立环境；没有修改公共 base 环境、系统驱动或网络设置。
